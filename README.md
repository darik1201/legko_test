# Замер скорости скачивания

Нужен Python 3.8 или новее. Установка библиотек не требуется.

Запуск:

```bash
python3 speed.py https://proof.ovh.net/files/1Mb.dat
```

В примере скачивается файл размером около 1 МБ, 10 раз подряд. Можно указать другую прямую ссылку на файл.

Скрипт последовательно скачивает файл 10 раз и выводит среднее время запроса, общий объём и среднюю скорость. Каждый ответ читается полностью.
Пример вывода
```
Среднее время запроса: 2.43 с
Скачано: 10.49 МБ
Скорость скачивания: 0.43 МБ/с
```

Объём указан в МБ (1 МБ = 1 000 000 байт), скорость — в МБ/с. Скорость считается как общий объём, делённый на суммарное время всех 10 запросов.
